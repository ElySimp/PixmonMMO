# Legacy MySQL Models Archive

These models belonged to the deprecated MySQL/mysql2 data layer and have been superseded by Mongoose 8 models in `backend/models/`:
- `User.js`, `UserProfile.js`, `DailyRewards.js` -> `backend/models/Player.js`
- `Inventory.js` -> `backend/models/Item.js`
- `QuestSystem.js` -> `backend/models/Quest.js`
- `Achievement.js` -> `backend/models/Player.js` (profile.selectedAchievements)
